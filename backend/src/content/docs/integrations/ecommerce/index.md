# E-commerce

Integrations that keep an e-commerce catalog — products, collections, prices, and availability —
in sync with an Interakt **Search Index**, so storefront search and chat always reflect your live
catalog.

> **Coming soon.** Guides for specific platforms (Shopify, Medusa, BigCommerce, and others) will
> land here. The shape mirrors the [Storyblok integration](../cms-dxp/storyblok/how-to-integrate-interakt-with-storyblok):
> a one-time backfill plus webhooks that re-ingest a product whenever it changes.
>
> Building one now? The [Storyblok guide](../cms-dxp/storyblok/how-to-integrate-interakt-with-storyblok)
> is a complete, transferable template — swap the Storyblok Content Delivery API for your platform's
> product API and map products to documents instead of stories.
